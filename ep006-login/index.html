C++ login server with Redis tokens

A login server checks passwords away from the game server's tick, and hands each login over through Redis as a one-time token.

Watch on YouTube

We let our players log in, through a login server that checks passwords away from the game's tick, and hands each login over as a one-time token in Redis. The game server loads the player with it and saves where they are, so you come back where you left off, and the client gets a login screen. This is episode 6 of a series about building an MMORPG from scratch in C++, with the focus on the engineering around the game.

Topics: Databases, Security
