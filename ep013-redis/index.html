Redis cache in C++: write-behind to MySQL

Saving each change to MySQL slows our server down with a few dozen players, so we put Redis in between, with a pipeline, an append-only file and a saver that writes to MySQL in batches.

Watch on YouTube

We stop our players losing their progress when the C++ game server crashes. Saving to MySQL after each tick falls behind at fifty players, so we put Redis in between, written in a single round trip each tick, and a saver of our own writes behind to MySQL. Then we crash the server, and the players come back where they were. This is episode 13 of a series about building an MMORPG from scratch in C++, with the focus on the engineering around the game.
