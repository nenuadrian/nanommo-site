Deploy a C++ game server to a VPS with Docker

Our game goes onto a VPS, deployed over SSH with Docker Compose, with the database kept private and certificates for the server's address.

Watch on YouTube

We deploy our game to a VPS on the internet, a DreamHost one with two virtual CPUs (the affiliate link is below). We decide what the internet gets to reach, write a production compose file and a deploy script that builds a commit on the server, and put the VPS under load with our bots. This is episode 19 of a series about building an MMORPG from scratch in C++, with the focus on the engineering around the game.
