nanoMMO

A software engineering perspective

In this series, we're going to build an MMORPG from scratch, both the client and the server. The focus is on the engineering around the game: Docker, CI, benchmarking, Prometheus and Grafana, MySQL, Redis, and profiling.

nanoMMO is the working title. It takes after nanochat, a repository by Andrej Karpathy, with code that's kept minimal and easy to hack on. That's what I'm going for here as well: a codebase that covers an MMO from one end to the other, which you can read, run yourself, and play with.

The episodes are on YouTube. The game's code is on GitHub, tagged at each step of each episode, so you can follow along. Its API docs are here.
