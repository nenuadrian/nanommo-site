    Playing my C++ MMORPG offline in a browser, without a server

    Our C++ MMORPG's client runs the world's own rules on its own, natively and in a browser tab, after a raylib bug turns each person's hand into a spindle in WebGL.

    Watch on YouTube

    Our C++ MMORPG plays offline: the client runs the world's rules on its own, from the library the server uses, so a browser starts straight into the world without a server. A local connection gives the client a world through the interface its network connection already has, at the server's tick, with the server's own code for inputs and for what a player is shown. In the browser, tall spindles stand by each person, which comes down to raylib sending WebGL its bone matrices untransposed, and a patch fixes it.
