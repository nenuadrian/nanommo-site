    Sharing my MMORPG's game rules between C++ server and client

    Our C++ MMORPG's world, and what each player is shown of it and what their inputs do, move out of the server into a library the client can run too.

    Watch on YouTube

    Our C++ MMORPG's game rules move out of the world server into a library of their own, so the client can run them too. The world, with its monsters, NPCs, levels and trades, builds without a database or a network, and the code that turns a player's inputs into the world's actions, and the world into what each player is shown, moves out of the server into two parts of that library, with tests of their own, while the server's older tests say it behaves as it did. This is episode 77 of a series about building an MMORPG from scratch in C++, with the focus on the engineering around the game.
