    Profiling a C++ game server with perf and Tracy

    We step the bots up until the server falls behind, find out where its time goes with perf, flame graphs and Tracy, fix the broadcast, and measure it again.

    Watch on YouTube

    We benchmark our C++ game server to see how many players it can take, and it falls behind past a thousand. Profiling it under load with perf and Tracy points at the broadcast, which serialised the whole world for each client, so we serialise it once a tick, and the server keeps up with twice the players. This is episode 8 of a series about building an MMORPG from scratch in C++, with the focus on the engineering around the game.
