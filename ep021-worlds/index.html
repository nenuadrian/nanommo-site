    Consul service discovery for a C++ game server

    Each game server is a world that registers with Consul, the client lists the worlds through the login server, and each world keeps its own players.

    Watch on YouTube

    We run several worlds instead of one, each registered with Consul through its HTTP API, with a heartbeat so that a world that crashes drops out of the list. The login server lists the healthy worlds, you pick one before you log in, Prometheus finds them through Consul too, and each world gets its own players. This is episode 21 of a series about building an MMORPG from scratch in C++, with the focus on the engineering around the game.
